### Для решения данной задачи на Node.js можно воспользоваться внешней сортировкой. 

- 1 разбивает исходный файл на временные файлы 

- 2 сортирует их и потом объединяет в один отсортированный файл 

- 3 временные файлы хранятся в папке temp/. 


Для запуска программы необходимо поместить файл input.txt с данными и запустить скрипт. 

node sortFile.js

После завершения выполнения программы будет создан файл output.txt с отсортированными строками.
